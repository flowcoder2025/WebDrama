# L1: 검수

## 역할
Evaluator 자동 채점 + 사용자 최종 확인

## L2 구성
- **Evaluator 자동 검증**: 4대 기준 채점, 재작업/재생성 판정
- **사용자 리뷰**: 최종 확인, 수정 요청 반영

## 담당
Evaluator (Quality Assurance)

## 채점 기준 (0~10점)
| 기준 | 비중 |
|------|------|
| 스토리 구조 | 30% |
| 비주얼 일관성 | 25% |
| 음성 품질 | 20% |
| 편집 완성도 | 25% |

## 판정
- 10점 → Pass → 사용자 리뷰
- 5~9.9점 → 피드백 + 재작업 (최대 10회)
- 5점 미만 → 전면 재생성
- 10회 초과 → 최고 점수 버전 + 피드백을 사용자에게 제시

## 출력
eval-report.json
