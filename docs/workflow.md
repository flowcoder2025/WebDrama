# WebDrama 워크플로우

## 1. 작품 시작 절차

1. **상위 프로젝트(Cowork)에서 작품 산출물 준비 완료 확인**
   - 단일 진입점 HANDOFF 문서 + 프롬프트북 + 캐릭터 레퍼런스 + 편집 규격
2. **WebDrama 작품 디렉토리 생성**
   - `projects/{작품}/PROJECT.md` 작성 (상위 SSOT 링크 + 원문 표)
   - `projects/{작품}/assets/*` 트리 생성
3. **이전 버전 보관** (기존 작업물 있는 경우)
   - `projects/{작품}_v<N>/` 또는 하위 `legacy/`로 보존

## 2. 수작업 CDP 단계 (이미지·영상)

### 2.1 원칙 (RAG `cdp-pikaso/00-core-principles.md` 준수)
- 브라우저 자동화 스크립트 작성 금지
- `cdp-utils.ts` + `node -e` 단계별 직접 제어
- 매 단계 검증 후 다음으로 진행

### 2.2 단계별
1. 브라우저 CDP 연결 확인 (port 9222)
2. Reference 등록 (캐릭터 → 로케 → 앵커 순)
3. Start Image 생성 (컷별 프롬프트북 참조)
4. 결과물 검증 (레퍼런스 부합 + 프롬프트 의도 반영)
5. 다운로드 (Node `https.get` + `&preview=1` 제거)
6. Kling 영상 생성 (Start Image → 모션 프롬프트)
7. 영상 다운로드

### 2.3 검증 원칙
- 생성물 확인 시 **작품 제작패키지 + 재설계 원칙** 동반 참조
- 이미지 형태 모호 시 단정 금지 → prompt 컨텍스트 대조 후 의문 제기
- 매 generate 직전 ref 개수 + 멘션 인식 확인

## 3. 자동화 단계 (TTS·BGM·Remotion)

### 3.1 현재 상태
- **미착수** (수작업 CDP 품질 안정화 후 착수)

### 3.2 착수 조건
- 사용자가 최종 판단으로 수작업 → 자동화 전환 승인
- 전환 시점 기준: 당시 확정된 수작업 패턴을 그대로 스크립트화

### 3.3 착수 시 복원
- `tsconfig.json` 재생성 (`src/` 구조 기반)
- `vitest.config.ts` 재생성
- `package.json` scripts 복원 (`eslint`, `tsc`, `vitest run`)
- `src/` 구현 (TTS · BGM · Remotion 모듈)

## 4. 튜닝 루프 (프롬프트 조정)

### 4.1 기본 사이클
```
생성 → Evaluator 채점 → 컷 의도 체크리스트 대조 → 프롬프트 diff → 재생성
```

### 4.2 Evaluator 서브에이전트 호출
- 트리거: 단일 결과물 또는 시퀀스 완성 후
- 기준: 작품별 `PROJECT.md` 품질 판정·재시도 표
- 결과: `eval-report.json` (통과 / 재작업 / 전면 재생성)

### 4.3 재작업 상한
- **10회**까지 재시도. 초과 시 최고 점수 버전 + 피드백을 사용자에게 제시 → 사용자 직접 판단

### 4.4 전면 재생성
- 5점 미만: 처음부터 다시 (프롬프트·레퍼런스·접근 전면 재검토)

## 5. 품질 게이트

### 5.1 컷 단위
- 작품별 의도 체크리스트 부합 여부 (예: `PROJECT.md` 캐릭터·로케·팔레트 제약)
- 레퍼런스 일치 (의상·액세서리·헤어)
- 프롬프트 의도 반영

### 5.2 시퀀스 단위
- 앵커 체인 연속성 (벽·소품·조명 일관)
- 프레임 체이닝 (`last→first seed`) 쌍 정합
- 립싱크 예외 클립의 phoneme 품질

### 5.3 에피소드 단위
- 런타임 준수 (EDL 기준)
- 팔레트 아크 (쿨→앰버 등 전환 규약)
- EP 간 미러 컷 정합 (수미상관이 있는 경우)

### 5.4 배포 단위
- 발사 전 N항 체크 (작품별 편집배포 규격 참조)

## 6. 세션 핸드오프

### 6.1 생성 조건
- 사용자가 세션 종료 전 명시 요청 시
- 대형 작업 중간 저장이 필요할 때

### 6.2 저장 위치
- `projects/{작품}/.session/SESSION_HANDOFF_<YYYYMMDD>.md`
- 과거 핸드오프는 쌓되 오래된 것은 사용자 판단으로 제거

### 6.3 내용
- 현재 작업 단계 (클립 ID, 단계)
- 브라우저 상태 (탭·모델·해상도)
- 미결 의사결정
- 다음 세션 첫 액션
