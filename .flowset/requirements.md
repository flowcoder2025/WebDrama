# 사용자 원본 요구사항 (수정 금지)
# 이 파일은 /wi:prd 확정 시 자동 생성됩니다.
# 에이전트가 이 파일을 수정하면 validate_post_iteration에서 위반으로 감지됩니다.

## 사용자 제약조건
- UI 불필요 — Claude가 프롬프트 받아서 작업하는 CLI 방식
- 혼자 사용
- Freepik은 API가 아닌 CDP(Chrome DevTools Protocol) 방식
- BGM은 로컬 GPU에서 ACE-Step 1.5XL로 생성
- TTS는 상업 이용 가능 + 음성 클로닝 + 한국어 완벽 지원 필수
- TTS 엔진은 Qwen3-TTS / GPT-SoVITS 둘 다 테스트 후 확정 (추상화 필수)
- Evaluator 10점 만점만 통과
- 최대 재작업 10회, 초과 시 사용자 판단
- 리서치 기반 시나리오 생성 (성공작 분석 + 트렌드)
- 검수 전 Evaluator 자동 검증 필수
- 에이전트 간 통신은 JSON 파일로만 (직접 호출 금지)

## 사용자 결정사항
- Freepik CDP 방식 채택 (MakeLanding 프로젝트 패턴 재활용)
- Remotion 채택 (React 기반 타임라인 편집, FFmpeg 직접 사용 대비 직관적)
- ACE-Step 1.5XL 채택 (로컬 GPU, 고품질 음악 자동 생성)
- TTS 추상화 구조 (Qwen3-TTS + GPT-SoVITS, 테스트 후 확정 또는 병행 사용)
- 하이브리드 에이전트 구조 (창작 1 + 실행 1 + Evaluator 1, 맥락 일관성 유지)
- Evaluator 판정: 10점=통과, 5~9.9=재작업(최대10회), 5미만=전면재생성

## 기능 요구사항 (L3 기준)
- 리서치/분석: 스토리 패턴 추출, 비주얼 패턴 추출, 후킹 패턴 추출, 인기 주제/키워드, 채널 벤치마킹
- 스토리/대본: 리서치 기반 구조 설계, 장면 분할+후킹, 캐릭터 대사, 나레이션, 다중 시안 프롬프트
- 에셋 생성: Freepik CDP 이미지(2K), Freepik CDP 영상(720p), 캐릭터 일관성, 모션 제어
- 음성/음악: TTS 캐릭터 음성 클로닝, 나레이션, 엔진 전환, ACE-Step BGM, 볼륨/페이드
- 편집/합성: Remotion 타임라인, 자막, 전환 효과, Shorts(9:16), 롱폼(16:9) 렌더링
- 검수: 4대 기준 채점, 재작업/재생성 판정, 사용자 리뷰, 피드백 반영
